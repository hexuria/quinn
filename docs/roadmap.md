# Roadmap

What this tree is, and what it is not taking on next. Crate names on crates.io are unset on purpose. Every package has `publish = false`. Nothing here has been published.

## Done in this milestone

- `view!`, `#[component]`, and `run!` expand to a Makepad widget tree. There is no WebView and no second layout engine. `run!` is the string shell. The examples do not use it.
- Counter, conditional, keyed list, form, retain, and the Tailwind gallery lower that syntax into Makepad script (`mod.state`, `on_render`, `on_click`, `on_change`). A save of `view.rs` under `--hot` updates classes, static text, show/for structure, and handlers in the same process. `mod.state` keeps the count, the keyed map, the toggle, and the typed string.
- P0 from [gap-analysis.md](gap-analysis.md) is in: row wrap, `Distribute`, `RowAlign`, flex weight, min/max, `Size::Rel`, per-side padding and margin, `class:` / `style:` / arbitrary values, closed multi-statement handlers, `<Show>` inside a row, and real button hover, down, and disabled colors. `examples/tailwind-gallery` shows them. `examples/keyed-list` has a per-row note.
- P1 is in: fragments, `#[prop]` options, `children` / `ChildrenFn` as script functions, `provide_context` / `use_context` on `mod.ctx`, an in-app `<Router>` that is not `leptos_router`, `widgets.Grid`, clip and scroll, RobotoFlex weights and `leading-*`, gradients and shadows, nested script objects, and `bind:value` that does not rewrite the input. `examples/app-shell` is the multi-page shell. The gallery's last section shows the new utilities.
- P2 is in: `<Suspense>` / `<Transition>` / `<ErrorBoundary>` / `<Portal>`, `sm:`/`md:`/`lg:`/`xl:` and `dark:`, parent-relative `absolute` / `inset-0`, paint-order `z-*`, nested context, `#[prop(into)]` literals, `hover:` on a `div`, and `focus:` on buttons and inputs. `examples/async-dashboard` is the screen. `align-content` and server functions are not in. Taffy is still not part of the plan.
- P3a is in: `LocalResource` / `Resource` / `Action` call a registered Rust async fn on a tokio worker. Results return through `SignalToUI` into `mod.state`. `dispatch` passes its argument. A source-signal change and `refetch()` bump the generation. A stale generation is dropped. A panic in the future is an error phase. A `Vec` of serde structs renders with `<For>`. Markup still hot-reloads while a request is in flight; the fn body needs a rebuild.
- P3b is in: a superseded or unmounted job aborts its tokio task. Drop before `Ready` increments `quinn::cancelled_count()`, which the dashboard shows as `Cancelled`. A resource may read several signals (`(id.get(), page.get())`) and `await` a chain of registered fns. An action may take a `Serialize` / `Deserialize` struct and return `Result<T, E: Display>`. The async body stays compiled Rust, keyed by the function idents. Markup hot-reloads. `if` / `match` / loops inside the closure are rejected. `QUINN_HTTP=1` with `--features net` GETs one public user list; without the variable the city list stays Manila / Cebu / Davao.
- The macOS Human Interface Guidelines are the design system: Inter in the macOS type scale, Apple system colors, and a Notes-style `examples/showcase`. SF Pro and SF Symbols are not bundled. See [design-system.md](design-system.md).
- The Linux X11 software-GL path runs the examples. The counter also runs as wasm under Chromium with SwiftShader.
- The showcase release APK runs on an Android 15 Pixel emulator (`x86_64`). See [ANDROID.md](ANDROID.md). The other examples do not embed `view.rs` and have not been packaged.
- Startup, latency, and live script reload share `post_draw_hook` with a hand-written Makepad counter.

## Left open

- macOS, Windows, and iOS have not been executed. [TESTING_ON_MACOS.md](TESTING_ON_MACOS.md) is the unchecked Mac list. [SETUP_LINUX_AND_ANDROID.md](SETUP_LINUX_AND_ANDROID.md) is the Linux host and the Android toolchain, including the Makepad counter APK. Quinn's showcase release APK is [ANDROID.md](ANDROID.md). The other Quinn examples have not been packaged.
- The script retain run (2,000 cycles, two bursts) keeps widgets at 4 and buttons at 1. RSS rests about 3 MiB above the start and does not climb again on the second burst. The old 400 MiB spike was the reactive `ScriptVm::eval` mount. The headless `MemorySurface` test still passes and is a different runtime.
- A `view.rs` edit the lowerer accepts hot-reloads, including a `<Show>` nested inside a `<For>` row. An edit in `src/` or a shape the lowerer rejects still needs a rebuild. `quinn::run!` shells are strings, so they are not watcher targets. The baseline counter's block is `examples/baseline-counter/src/main.rs`.
- The style language is the utility list in [compatibility.md](compatibility.md). Server functions, an async body that is not a chain of named `quinn::job` fns, `align-content`, and Taffy are not in the plan. The router does not speak URLs. A nested provider shadows for its subtree and restores the previous value; the root `mod.ctx` seed does not reset on reload. Changing an async fn in `src/jobs.rs` needs a rebuild.
- `bind:value` leaves the input's `text` field alone, so the caret stays, and a sibling label still updates. `value=` with `on:input` still writes `text:` on each `render()`, and that caret can jump. `examples/form` is the second path.
